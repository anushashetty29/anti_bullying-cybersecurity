# CyberShield – Anti-Bullying Cybersecurity Platform

## Overview

CyberShield is a web-based platform designed to help identify, report, and manage cyberbullying incidents. The system provides a secure environment where users can report harmful content, raise complaints, and promote safer online interactions.

## Features

* User Registration and Login
* Cyberbullying Incident Reporting
* Complaint Management System
* Secure Data Storage
* Responsive User Interface
* Dashboard for Monitoring Reports
* Cyber Safety Awareness Resources

## Installation

1. Clone the repository

git clone https://github.com/anushashetty29/anti_bullying-cybersecurity.git

2. Install dependencies

npm install

3. Start the server

node server.js

4. Open the application in your browser.
